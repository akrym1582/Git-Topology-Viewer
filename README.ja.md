# Git トポロジービューアー

[English](README.md)

リポジトリの **コミット DAG** からブランチとタグの関係を確認するための VS Code 拡張機能です。ビューアーが「どのブランチから作られたか」という親子関係を推測することはありません。

## 機能

- ローカルブランチと、必要に応じたタグ・リモートブランチの縦方向の関係図。
- Git DAG 上で最も近い古い可視参照グループへ、各グループから1本だけエッジを接続。
- コミットノード、コミット件数、コミット範囲の展開・折りたたみは表示しません。
- 参照を選択すると履歴を確認できます。`main` は全履歴、他のブランチは関係図上の直近の基準参照との merge-base 以降を表示します。
- マージベース、固有コミット、行統計、変更ファイルを含む参照比較。
- マージベース、固有コミット、行統計、変更ファイルを含む参照比較。
- 履歴のコミットを選択すると、変更ファイルと行統計を確認できます。
- VS Code 標準の差分エディターで開く、読み取り専用のブランチ差分。チェックアウトは必要ありません。
- VS Code の Git 拡張、`gitTopology.gitPath`、`PATH` の順に Git CLI を検出。

## ビューアーを開く

Git リポジトリを含むフォルダーを開き、左側のアクティビティバーにある **Git トポロジー** アイコンから **Git トポロジービューアーを開く** を選びます。コマンドパレットの **Git トポロジー: ビューアーを開く** からも実行できます。

## ローカルで実行する

```powershell
npm install
npm run build
```

このフォルダーを VS Code で開き、**F5** を押します。Extension Development Host で Git リポジトリを開いた後、アクティビティバーの **Git トポロジー** アイコンを使います。

### Webview スモークテスト

固定バージョンの Chromium を一度インストールしてから、本番用 Webview バンドルをレンダリングし、参照比較を実行してスクリーンショットを保存します。

```powershell
npm run smoke:install
npm run smoke:webview
```

スクリーンショットは `artifacts/webview-smoke.png` に出力されます。環境、テストの自動検証、目視確認のチェックリスト、トラブルシューティングは `.agents/skills/git-topology-webview-smoke-test/` にあります。

## 設計

拡張機能は、最初に `git for-each-ref` と `git rev-list` を使って SHA、親コミット、参照の要約を読み込みます。不変の DAG を可視の参照グループへ投影し、途中に別の可視参照がない関係だけをエッジとしてレイアウトします。比較結果とファイル内容は、必要になったときだけ Git CLI から読み込みます。
